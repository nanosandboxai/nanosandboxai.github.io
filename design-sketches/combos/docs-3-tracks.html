MCP Servers

MCP servers give an agent extra tools. Each one runs inside the agent's own microVM, so it gets the same walls the agent does.

Track Extend · page 1 of 5 · ▮▮▮▮▮

Add a server to sandbox.yml

List servers under your agent in sandbox.yml, then run nanosb apply. Configuration is declarative: there is no in-TUI hot-reload.

Pass secrets

Servers that need a token read it from the sandbox environment. Secrets are injected per sandbox, never mounted.
