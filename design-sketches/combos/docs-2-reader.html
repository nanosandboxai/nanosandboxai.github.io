Installation

Install the nanosb CLI on your system.

v0.3.02 min readupdated 2026-11-26

Install on macOS or Linux

The fastest way to install the nanosb CLI on macOS or Linux is with the official shell installer:

bash
$ curl -fsSL https://github.com/nanosandboxai/nanosandbox/releases/latest/download/install.sh | bash

The script detects your platform, downloads the correct binary, and places it on your PATH.

What gets installed

ComponentDescription
nanosbCLI binary for creating and running microVM sandboxes
libkrunfwGuest kernel firmware loaded at VM boot
gvproxyUser-space networking proxy for bridge networking
exec-agentIn-guest exec agent used by nanosb exec
NoteBinaries are installed to ~/.nanosandbox/bin. Set NANOSANDBOX_HOME to install somewhere else.
bash · custom location
$ NANOSANDBOX_HOME=/opt/nanosandbox curl -fsSL https://github.com/nanosandboxai/nanosandbox/releases/latest/download/install.sh | bash

Verify the installation

After installing, confirm the CLI is working:

bash
$ nanosb --version

Platform support

Nanosandbox supports macOS Apple Silicon (stable) and Linux x86_64 (live-verified). See System Requirements for full platform details.
