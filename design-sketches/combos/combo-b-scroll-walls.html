NANOSANDBOX

VM-Isolated Sandboxes for AI Code Agents

Deploy AI agents in hardware-isolated microVMs with sub-second boot times. OCI image support, cross-platform (macOS, Linux), and built-in multi-agent TUI for concurrent development workflows.
