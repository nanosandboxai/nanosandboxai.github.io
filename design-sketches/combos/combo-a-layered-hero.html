Features

    
VM-Level IsolationEach sandbox runs in its own microVM via libkrun with an independent kernel

    
Sub-Second Boot TimesOptimized libkrun startup for near-instant sandbox creation

    
OCI Image SupportPull from Docker Hub, GHCR, or any private registry

    
Multi-Agent TUIRun multiple AI agents concurrently in panel-based terminal UI

    
Project MountingVirtioFS mounts with automatic git integration and branch tracking

    
MCP Server SupportModel Context Protocol integration for agent tooling

  


  
Common Commands

    
nanosb pull <IMAGE>Pull an OCI image from a registry

    
nanosb run <IMAGE> [CMD]Run a command in a new sandbox

    
nanosb exec <ID> <CMD>Execute command in running sandbox

    
nanosb psList running sandboxes

    
nanosb doctorCheck runtime prerequisites
