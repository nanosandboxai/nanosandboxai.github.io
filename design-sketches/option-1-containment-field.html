One cell per agent

Hover a cell to see its wall. Each feature is a layer of the same promise: what happens in the sandbox stays in the sandbox.

VM-01 · libkrun

VM-level isolation

Independent guest kernel per sandbox. No shared namespaces to escape through.

VM-02 · boot

Sub-second boot

Optimised libkrun startup makes a fresh VM cheaper than reusing a dirty one.

VM-03 · oci

OCI images

Pull from Docker Hub, GHCR or a private registry. Your existing images just work.

VM-04 · tui

Multi-agent TUI

Claude, Codex and Goose side by side in panels, each in its own VM.

VM-05 · virtiofs

Project mounting

VirtioFS mounts with git branch tracking, so the agent works on a clone.

Six commands to cage an agent

The CLI feels like Docker. The isolation feels like a separate machine.

nanosb pull <image>Pull an OCI image
nanosb run <image> [cmd]Run in a fresh sandbox
nanosb exec <id> <cmd>Exec into a running sandbox
nanosb psList running sandboxes
nanosb stop <id>Stop a sandbox
nanosb doctorCheck runtime prerequisites
