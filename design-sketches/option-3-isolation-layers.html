Read the stack from the top down

Scroll through each layer. The diagram above lights the wall you are reading about, and the stack spreads apart as you go.

L4 · agent

The agent runs as root, in a room of its own

Claude, Codex or Goose gets full control of an OCI image like python:3.12-slim. Nothing it does touches your shell.

L3 · guest kernel

Its own kernel and syscall filter

Every sandbox boots an independent kernel. Syscall filtering and package-install policies apply inside the guest.

L2 · microVM

libkrun microVM, sub-second boot

A minimal VM with VirtioFS project mounts and git branch tracking. The agent edits a clone, not your working tree.

L1 · hypervisor

Hardware virtualization

Apple Hypervisor.framework on Apple Silicon, KVM on Linux. The CPU enforces the boundary.

L0 · host

Your machine stays clean

Secrets are injected per sandbox, never mounted. nanosb rm leaves nothing behind.
