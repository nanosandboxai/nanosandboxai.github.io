A whole VM for your agent, ready in 180 ms.

Nanosandbox runs AI code agents in hardware-isolated microVMs with their own kernel. Fast enough that you start a fresh one for every task.

curl -fsSL https://github.com/nanosandboxai/nanosandbox/releases/latest/download/install.sh | bash
nanosb run python:3.12-slim --agent claudetrace · apple m3 · hvf ·

Familiar CLI

If you know Docker, you already know most of it.

nanosb pull <image>Pull an OCI image
nanosb run <image> [cmd]Run in a new sandbox
nanosb exec <id> <cmd>Execute in a running sandbox
nanosb psList running sandboxes
nanosb doctorCheck prerequisites
