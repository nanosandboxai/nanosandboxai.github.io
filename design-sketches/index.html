Five redesign directions for nanosandbox.ai

Each sketch is a working home page with real copy, the coral accent from today's site, and one motion idea built around sandboxing. Previews below are live and scaled down; open any of them full size to see the motion and try hover states.

Today: monospace everywhere, boxed sections in a single column, a typing terminal demo and a typing nav. Strong identity, but every section has the same weight and nothing shows what isolation actually means.

Option 1 · dark · cinematic

Containment Field

The hero is a live canvas: each agent is a glowing particle bouncing inside its own microVM cell. When it hits a wall the wall flashes and logs a blocked syscall.

motion
Canvas physics, wall-hit flashes, typing terminal, scroll reveals, hover shows each cell's wall
type
Geist + Geist Mono
best for
A launch moment; makes "isolation" visible in two seconds
effort
Medium. One canvas component, the rest is Tailwind

Option 2 · evolves today's look

Live TUI Console

The whole page becomes the multi-agent TUI. Panes boot in, three agent panes stream their own logs, and features are listed as a process table.

motion
Pane clip-in boot sequence, streaming logs per agent, boot-time bars, blinking cursor
type
Martian Mono
best for
Keeping the terminal identity while making it feel alive and current
effort
Low. Reuses the existing terminal-demo logic and tokens

Option 3 · blueprint · explanatory

Isolation Layers

An isometric exploded stack: host, hypervisor, microVM, guest kernel, agent. Scrolling spreads the layers and lights the one you're reading about.

motion
3D CSS stack, scroll-linked layer spread, step highlighting, idle cycling
type
Instrument Sans + DM Mono
best for
Security-minded buyers who need to understand why a VM beats a container
effort
Medium. Pure CSS 3D, no library

Option 4 · playful · community

Agent Arena

Bento grid where every agent sits in a cage card. Hover and the bars drop shut. A leaderboard teases the coming caging tournament.

motion
Bouncy cage bars on hover, headline cage drop, agent marquee, boot counter, leaderboard fill
type
Bricolage Grotesque + JetBrains Mono
best for
Growth and shareability; ties straight into the agents and tournament pages
effort
Low to medium

Option 5 · minimal · precise

Boot Timeline

Calm product page with one orchestrated moment: a real boot trace from 0 to 180 ms. A playhead sweeps the lanes and the headline number counts with it.

motion
Single replayable trace animation, underline nav, quiet hover shifts
type
Inter Tight + IBM Plex Mono
best for
Developer trust; reads like infrastructure you'd put in production
effort
Low. Easiest to keep consistent across docs
